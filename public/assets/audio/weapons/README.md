# Набор выстрелов Echo Front

Готовые игровые монофонические MP3, 48 кГц. Существующие звуки и игровая логика не изменены.
Одиночные звуки предназначены для одного игрового события; файлы с суффиксом burst содержат готовую очередь и не должны воспроизводиться на каждое событие.
Автомат и пистолет-пулемёт представлены также отдельным фрагментом последнего импульса записи; это монтаж, не отдельный оригинальный дубль для автомата.
Источники: Sonniss GameAudioGDC 2020 и 2021–2023; оригинальные записи принадлежат соответствующим правообладателям. Используются в составе Echo Front, не распространяются как самостоятельная коммерческая библиотека.
Точные источники и номера звукового микроскопа указаны в catalog.json.
