# Материалы и разрушение

Слои обработаны для игрового пространственного воспроизведения. Источники Sonniss GameAudioGDC 2015, 2020, 2021–2023 и 2024. Игровое использование по лицензии https://sonniss.com/gdc-bundle-license/; записи не являются отдельной распространяемой библиотекой. Оригиналы принадлежат соответствующим правообладателям. Номера микроскопа и источники указаны в catalog.json. WAV используется для бесшовных циклов, MP3 для отдельных событий.
