# Материалы и разрушение

Слои обработаны для игрового пространственного воспроизведения. Источники Sonniss GameAudioGDC 2020 и 2021–2023. Оригиналы принадлежат соответствующим правообладателям. Номера микроскопа и источники указаны в catalog.json. WAV используется для бесшовных циклов, MP3 для отдельных событий.
