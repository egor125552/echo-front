# Смертонос и мини-ядерка

Независимые монофонические слои для игрового пространственного звука. В каталоге указаны источники и номера звукового микроскопа. Исходники Sonniss GameAudioGDC 2020 и 2021–2023; права на оригинальные записи принадлежат их владельцам. Художественная звуковая постановка, не физическая модель.
