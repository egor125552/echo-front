# Core audio sources

These files are the reusable starting audio set for Echo Front.

- `automatic-shot.mp3` — reused from `egor125552/-archipelago-/public/assets/audio/free-roam-v25/automatic-shot.mp3`.
- `death-full.mp3` — reused from `egor125552/-archipelago-/public/assets/audio/free-roam-v25/death-full.mp3`.
- `step-1.mp3` through `step-4.mp3` — reused from `egor125552/-archipelago-/public/assets/audio/free-roam-v25/`.
- `pistol-shot.mp3` — MP3 conversion of the exact pistol recording used by Archipelago: `Gabrielsgp/hand-shotter`, commit `a9e2dac862291cbff1af8e2c3e82922c3aeb726c`, `songs/163456__lemudcrab__pistol-shot.wav`.

Keep gameplay code referring to these stable paths under `public/assets/audio/core/`.
